# FoodRescue — Use Case Diagram

## 3.2 Use Case Diagram

The Use Case Diagram represents the interactions between the four primary FoodRescue actors and the major functions provided by the system.

### Primary Actors

- Donor
- Recipient
- Volunteer
- Administrator

### Major Use Cases

#### Donor
- Register
- Login
- Manage Profile
- Manage Food Listings
- View Requests
- Approve / Reject Request
- Confirm Handover
- View Donation History
- View Impact Statistics

#### Recipient
- Register
- Login
- Manage Profile
- Browse / Search Food
- Request Food
- Track Request
- View Allocation
- Confirm Receipt
- View Request History

#### Volunteer
- Register
- Login
- Manage Availability
- View Assignments
- Accept / Reject Assignment
- Update Pickup Status
- Confirm Pickup
- Update Delivery Status
- Confirm Delivery
- View Assignment History

#### Administrator
- Login
- Manage Users
- Verify Recipient
- Monitor Food Listings
- Monitor Requests and Allocations
- Manage Issues / Disputes
- Manage Food Categories
- View Reports / Statistics
- Manage Notifications / Settings
